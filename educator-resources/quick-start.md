# Educator Quick Start Guide

**The fastest way to run your first Bitcoin / Layer 2 lesson**

This short guide gives you the minimum viable path from zero to running a successful first session.

## 1. Assess Your Audience (2 minutes)

Ask yourself these three questions:

- What is their current level of Bitcoin knowledge? (None / Some / Familiar with crypto)
- What is their main goal? (Understand money, understand technology, practical skills)
- What is the time available? (One lesson, series of lessons, workshop)

## 2. Pick One Toolkit

Use the [Educator Blueprint Decision Tree](../educator-blueprint.html) and choose **only one** starting kit:

- **Complete beginners** → Beginner Kit
- **Students who know other crypto** → Intermediate / Layer 2 Kit
- **Ideologically motivated audience** → Advanced Kit

Do not try to cover everything in the first session.

## 3. Run Your First Session

**Recommended structure (45–60 minutes):**

| Time       | Activity                          | Tool                          |
|------------|-----------------------------------|-------------------------------|
| 0–5 min    | Hook + real-world example         | Your own story or current news |
| 5–20 min   | Core concept (sound money / self-custody / Layer 2) | Slides from chosen kit |
| 20–35 min  | Interactive activity              | Worksheet or demo             |
| 35–45 min  | Discussion + questions            | Jargon Buster (live)          |
| 45–50 min  | Wallet demo (optional)            | Layerz Wallet                 |

## 4. Use the Jargon Buster During Teaching

Keep the [Jargon Buster](../faq.html#jargon-buster) open in a second tab.

When students ask about a term, search it live. This models good practice and removes fear of “not knowing everything”.

## 5. After the Session

- Ask students what surprised them most.
- Collect one piece of feedback.
- Decide if you want to run a follow-up session using the next kit in the sequence.
